L'objectif est de développer une application console permettant de gérer différents éléments liés aux compétitions sportives.

* Gestion des disciplines
* Gestion des athlètes

* Gestion des résultats
* Persistance des données

`Java` `JDBC` `MySQL` `UML`

Ce projet m'a permis de mettre en pratique la **programmation orientée objet, la connexion Java/MySQL avec JDBC, la conception UML et l'organisation d'une application logicielle**.
